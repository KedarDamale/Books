02. Generate or check TypeScript boundary types.
03. Validate responses at runtime where needed.
04. Test authorization across UI and service.
05. Trace errors without exposing internals.
06. Compare framework behavior under equivalent requests.
Completion: Implement one small API contract in a chosen backend and consume it from React, then compare how the other two backends would preserve its semantics.
