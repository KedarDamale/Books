# Mathematics: a structured reading atlas

This repository is a topic-by-topic route through mathematics, from numeracy and proof writing to graduate subjects and research directions. It is a **reading plan**, not a collection of book files. Start at [Mathematics](Mathematics/README.md).

Each leaf folder contains `book_name.txt`. That file names a primary book, a precise topic or chapter theme to read, a detailed checklist of ideas to master, and a completion exercise. Read the indicated portion of a book, solve problems, then move on. You do **not** have to read every recommended book cover to cover. Chapter numbers and pages vary by edition, so the stable selectors here are section titles and concepts. Use the [complete topic index](Mathematics/TOPIC_INDEX.md) to jump directly to any unit.

The order is a dependency guide, not a rigid calendar: foundations → calculus, linear algebra, proof and discrete mathematics → analysis and algebra → advanced and applied fields. Some branches can be studied in parallel. [The subject map](Mathematics/README.md) shows the entry points and prerequisites.

Mathematics is an open-ended research field; no static repository can literally exhaust it. This atlas aims to cover the major school, undergraduate, graduate, applied, and research-facing branches at a useful level of detail. The [contribution rules](AGENTS.md) explain how to extend it without creating vague subject folders.

No copyrighted book PDFs are stored here. Find the cited books through a library, publisher, or legitimate open edition. The [American Institute of Mathematics approved open-textbook catalog](https://textbooks.aimath.org/textbooks/approved-textbooks/) and [OpenStax mathematics catalog](https://openstax.org/k12/math) are useful starting points.
