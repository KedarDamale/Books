# Mathematics study map

Read the numbered domains in broad order, but use the leaf units as the actual work plan. The [complete topic index](TOPIC_INDEX.md) links to every unit. In each `book_name.txt`, **Read** identifies the relevant portion of a book and **Study checklist** names what to learn. Finish the completion task before advancing. A source can recur across units; read only the selected parts each time.

## Entry routes

- New to mathematics: 00–05, then 06–08.
- Comfortable with school mathematics: begin at 04–08 and fill proof gaps in 05.
- Building rigorous undergraduate foundations: 05–16, with 06–08 as prerequisites.
- Applied or computational focus: 06–08, 15–20, then 23–26.
- Pure mathematics and research: 09–14, 16, 21–22, 25, then 27.
