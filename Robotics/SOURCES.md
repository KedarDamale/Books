# Robotics sources and reading policy

64 sources are used by the study units. Metadata and selected coverage were checked against author, university, publisher, standards-body, or project documentation on 2026-10-26.

This repository stores original study objectives, reading selectors, and projects. It does not redistribute the books or reproduce their exercises. A completion project may combine concepts from multiple completed prerequisites; it is not a claim that an identical project appears in the primary source.

Obtain commercial books and full standards through a legitimate library or publisher. Open books, institutional notes, author-hosted manuscripts, and official manuals are linked to their approved destinations. An official catalog, table of contents, or documentation source repository can verify a source when its rendered website blocks automated readers; that does not imply free access to the full commercial book.

The `Primary book` field is retained for format consistency. `Source type` distinguishes books, manuals, course materials, papers, datasheets, and standards previews. Read the named themes and required second-source selections, not every recurring source in full. Optional extension books deepen a topic without making an entire extra book mandatory.

Framework and hardware documentation must match the version and actual component used in an experiment. A concrete MCU or vendor guide is a teaching reference, not a hardware purchase recommendation. Check ratings and operating conditions in exact device and material documentation before a physical design.
